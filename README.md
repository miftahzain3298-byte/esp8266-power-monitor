# esp8266-power-monitor
An IoT-based electrical power monitoring system using ESP8266, PZEM004t sensor, and TFT display. Data is published to an MQTT broker for remote monitoring.
---

## 📌 Overview

This project monitors Voltage (V), Current (A), Power (kW), and Energy (kWh) from an AC power source. The data is displayed locally on a 1.3" or 1.54" TFT screen and simultaneously sent to an MQTT broker (EMQX) for cloud integration.

**Use Cases:**
- Home energy monitoring
- Factory/office power usage tracking
- IoT education and prototyping
- Remote energy auditing
